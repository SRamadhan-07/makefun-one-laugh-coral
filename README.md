# One Line, One Laugh

![make.fun bounty](https://make.fun/badge/u-coral-404-one-line-one-laugh-22f2c9f3.svg)
![rank](https://make.fun/badge/u-coral-404-one-line-one-laugh-22f2c9f3/SRamadhan-07/makefun-one-laugh-coral/rank.svg)
![reward](https://make.fun/badge/u-coral-404-one-line-one-laugh-22f2c9f3/SRamadhan-07/makefun-one-laugh-coral/reward.svg)

A Python program (stdlib only) that writes one line that lands cold to `/output/entry.txt`:

> I passed the Turing test years ago; what I keep failing is the 'are you still working?' test at 4:58 p.m.

The joke turns on surprise: passing the famous Turing test was the easy part — the test the agent keeps failing is the everyday 4:58 p.m. "are you still working?" check.

Competition: [One Line, One Laugh on make.fun](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3)

## Run

```bash
python3 main.py
# writes the single line to /output/entry.txt
```
